# Viajea - Landing Page

Landing page para la agencia de viajes Viajea, especializada en viajes migratorios, de trabajo y vacacionales.

## Características

- Diseño responsive y moderno
- Sección de noticias migratorias
- Formulario de contacto integrado con HubSpot
- Integración con WhatsApp
- Soporte para modo oscuro
- Optimizado para SEO

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- HubSpot Forms

## Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/viajea-click-landing.git
```

2. Abre el archivo `index.html` en tu navegador.

## Configuración

Para configurar el formulario de contacto:

1. Reemplaza el ID de HubSpot en el formulario con tu propio ID
2. Actualiza los enlaces de redes sociales con tus perfiles
3. Modifica el número de WhatsApp con tu número de contacto
